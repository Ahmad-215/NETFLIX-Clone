# 🎬 Netflix Clone - Frontend Web Application

A responsive and visually stunning Netflix Clone built using modern web development practices. This project replicates the core UI/UX of Netflix, featuring movie dynamic previews, category rows, and a modern streaming interface.

---

## 📸 Preview

![Netflix Clone Banner](https://images.unsplash.com/photo-1574375927938-d5a98e8ffe85?q=80&w=1200&auto=format&fit=crop)

---

## ✨ Features

- 🎯 **Hero Banner:** Dynamic featured title preview with action buttons.
- 🍿 **Media Grids:** Horizontal movie & TV show showcase rows.
- 📱 **Fully Responsive:** Smooth layout transitions across Mobile, Tablet, and Desktop.
- 🎨 **Modern Styling:** Clean UI design mimicking Netflix's iconic dark aesthetic.

---

## 🛠️ Tech Stack

- **Frontend:** HTML5, CSS3, JavaScript (ES6+)
- **Icons & Fonts:** FontAwesome / Google Fonts
- **Deployment:** Vercel
